## 名称与检索结果

项目最初使用的“聆音”（不是“暂音”）是一个常见中文词。公开检索发现过“聆音播放室”“聆音音乐”等同名或近名产品，容易造成来源混淆，因此公开发布前将应用名改为“曲栈”。

“曲栈”由“曲”和“队列栈”组合而来，与项目最核心的持久播放队列功能对应。GitHub 的精确仓库名检索暂未发现同名播放器，GitHub 仓库建议使用 `quzhan-local-player`。这只能说明目前没有发现明显的同名开源项目，不能代替商标数据库检索，也不能保证不存在未公开或未检索到的商标权。

目前没有证据表明本项目使用了其他播放器的代码、图标、专辑封面或宣传素材。若计划商业发布、上架应用商店或进行付费分发，建议：

公开仓库意味着其他 GitHub 用户可以查看、Fork 和通过平台机制使用你的项目。GitHub 的服务条款与仓库许可证共同影响别人可以做什么。当前项目采用“保留所有权利”的自定义声明，因此不要把它描述成 MIT 或 GPL 开源项目。
